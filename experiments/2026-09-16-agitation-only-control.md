## 1. 目的

SPP(ソリューションプラズマ)処理による試料の変化(欠陥導入・導電化・表面組成変化など)が、
**放電(プラズマ)そのものに起因するのか、それとも処理中の機械的撹拌(500 rpm)や粒子間衝突・
摩耗に起因するのか**を切り分ける。

現行の中心結論「SPPは炭化装置でなく欠陥/表面活性化エンジンである」(確度80%、`CLAUDE.md`)は、
観測される変化の主因がプラズマ放電であることを暗黙に前提としている。この前提そのものを
検証していないため、本実験でその内部妥当性を確認する。

## 2. 仮説

- **仮説**: 撹拌のみ(高電圧OFF)では、通常のSPP処理試料と比べて有意な変化が生じない。
  すなわち、観測される効果の主因はプラズマ放電である。
- **確度**: 60%程度(仮説)。SPPは50 kHz/3 kVの局所放電でエネルギー密度が機械的撹拌より
  大きいと考えられる(`CLAUDE.md`のエネルギー収支の記述と整合)ため、放電が優勢と予想されるが、
  タングステン(W)電極摩耗は撹拌とも結合しうるため、完全に独立な変数ではない点に注意。

## 3. 実験群の設計

| 群 | 条件 | 目的 |
|---|---|---|
| A: 通常SPP処理群 | 高電圧3 kV ON、撹拌500 rpm、既定時間 | 既存のベースライン(比較対象) |
| B: 撹拌のみ群(対照) | 高電圧OFF、撹拌500 rpm、同一時間・同一溶媒・同一容器 | プラズマなしでの変化量を測定 |
| C: 未処理群(参考) | 処理なし(出発material) | 変化の絶対量の基準点 |

- 溶媒・試料濃度・容器・撹拌時間はA/B間で完全に同一にする(単一変数の原則)。
- 可能であれば同一バッチの出発原料から A/B/C を同時に分取し、原料ロット差を排除する。

## 4. 未確認事項(要現物確認)

- **不明**: SPP装置で高電圧のみをOFFにし、撹拌だけを動作させるモード切替が装置仕様上可能か。
  これができない場合、代替として撹拌機のみで同条件を再現する方法を検討する必要がある。
- **不明**: 高電圧OFF時にW電極からの摩耗混入量がどう変化するか(放電がないため減少する可能性はあるが未確認)。

**Go/No-Go判定**: 上記のモード切替が装置上不可能と判明した場合、別途の撹拌機で同条件
(容器・撹拌翼形状・回転数・温度)を再現できるかを検討し、装置間差を交絡因子として
考察に明記する。

## 5. 必要な装置・試薬

既存インベントリ(`CLAUDE.md`記載)の範囲内で完結する見込み。追加購入は不要。

- SPP装置(高電圧OFFモードの可否は要確認)
- 下流測定: Raman分光(532/785 nm)、XRD、SEM-EDS、4探針・粉体抵抗セルによる導電率測定、BET比表面積測定
- 卓上遠心機(洗浄・回収work用)

## 6. 手順(概略)

1. 出発原料(ZIF-67)を3分割し、群A・B・Cに分ける。
2. 群Aは通常条件でSPP処理(高電圧3 kV ON、撹拌500 rpm)。
3. 群Bは高電圧OFFのまま、群Aと同一時間・同一撹拌条件で処理(モード切替が不可能な場合は代替撹拌機を使用し、その旨を記録)。
4. 群Cは処理を行わず、出発原料のまま保管。
5. 各群を同一手順で洗浄・乾燥する。
6. 各群についてRaman・XRD・SEM-EDS・導電率・BETを測定する。

## 7. 評価項目と判定基準

| 測定項目 | 群A vs 群B の比較で見るもの |
|---|---|
| Raman(D/G比) | 欠陥量の変化がプラズマ由来か撹拌由来かを切り分け |
| XRD | 結晶構造変化(黒鉛化・相変化)の有無 |
| SEM-EDS | W混入量、元素組成変化 |
| 導電率(4探針) | 導電化がプラズマ由来か撹拌由来かを切り分け |
| BET比表面積 | 多孔性の破壊が放電由来か機械的摩耗由来かを切り分け |

## 8. 成功/失敗どちらでも結論になるか

**なる**。

- 群Bで有意な変化が出なければ → 「効果はプラズマ由来」という中心主張(確度80%)が実測で補強される。
- 群Bでも群Aと同等の変化が出れば → これまでの「欠陥導入」等の帰属の一部を撹拌由来として
  再解釈する必要があり、それ自体が卒論の重要な限界・考察になる
  (`docs/research-integrated-record.html` 第15章の批判的検証に追加すべき反論として位置づけられる)。

## 9. 既知の交絡因子・注意点

- W電極摩耗混入は撹拌のみ群(B)でも起こりうる。放電がないことで摩耗が減る可能性はあるが未確認。
- 撹拌のみでも粒子破砕による比表面積変化(BET)が生じうるため、結果解釈時は摩耗由来の
  物理的破砕と、化学的な孔破壊を区別する視点を持つこと。
- 本実験は既存の5類型(A〜E)・全SPP導電化3経路のいずれとも独立した「内部妥当性を担保する
  対照実験」であり、今後どの実験設計版を採用する場合にも横断的に有用。
